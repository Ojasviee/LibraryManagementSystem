# Library Management System – Documentation

# 1. Introduction
The Library Management System is a Java-based console application designed to manage books and members in a library. It simplifies basic operations such as adding books, registering members, borrowing and returning books.

# 2. Objectives
- To apply Object-Oriented Programming concepts
- To manage library records efficiently
- To implement encapsulation using getters and setters
- To build a menu-driven Java application


# 3. System Description

# 3.1 Book Class
Attributes:
- ISBN
- Title
- Author
- Genre
- Availability status

Responsibilities:
- Store book information
- Track availability

# 3.2 Member Class
Attributes:
- Member ID
- Name
- Contact
- Borrowed books list

Responsibilities:
- Borrow books
- Return books

# 3.3 Library Class
Responsibilities:
- Store all books and members
- Search books
- Manage borrowing and returning logic

# 3.4 LibrarySystem Class
- Acts as the main entry point
- Provides menu-driven interface
- Handles user input

# 4. OOP Concepts Used
- Encapsulation
- Classes and Objects
- Data Hiding
- Modularity

# 5. Conclusion
This project successfully demonstrates a real-world library management scenario using Java and OOP principles. It is suitable for academic submission and practical understanding.
